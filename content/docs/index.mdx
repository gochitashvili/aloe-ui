**23rd** is a [shadcn/ui](https://ui.shadcn.com) registry of opinionated UI components built for people who ship.

Made by **radiumcoders** (aka **Jay**).

## What this is

A curated set of components with strong defaults — less boilerplate, clearer decisions, and a look that stays consistent across projects. Install what you need through the shadcn CLI, then customize in your own codebase like any other registry item.

## Why opinionated

Most component kits hand you every option. 23rd picks a direction: spacing, radius, interaction patterns, and composition rules that already feel finished. You can still override anything — you just start from a sharper baseline.
