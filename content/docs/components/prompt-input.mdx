## Installation

<CliCommand command="shadcn@latest add @aloe-ui/prompt-input" />

Or install straight from the public GitHub source registry:

<CliCommand
  npm="npx shadcn@latest add gochitashvili/aloe-ui/prompt-input"
  pnpm="pnpm dlx shadcn@latest add gochitashvili/aloe-ui/prompt-input"
  yarn="yarn dlx shadcn@latest add gochitashvili/aloe-ui/prompt-input"
  bun="bunx --bun shadcn@latest add gochitashvili/aloe-ui/prompt-input"
/>

## Usage

```tsx
import { PromptInput } from "@/components/ui/aloe/prompt-input"

export function Example() {
  return (
    <PromptInput
      placeholder="Ask anything…"
      onChange={(event) => console.log(event.target.value)}
    />
  )
}
```

## Props

Accepts standard `<input>` props.

| Prop | Type | Default |
| --- | --- | --- |
| `placeholder` | `string` | `"Ask anything…"` |
| `className` | `string` | — |
| `…` | `ComponentProps<"input">` | — |
