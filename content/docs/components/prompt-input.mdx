## Usage

```tsx
import { PromptInput } from "@/components/ui/aloe/prompt-input"
```

```tsx
<PromptInput placeholder="Ask anything…" />
```

## Composition

```txt
PromptInput
├── InputGroup
│   ├── InputGroupTextarea
│   ├── InputGroupAddon (start) → DropdownMenu + Button
│   └── InputGroupAddon (end) → Button
```

## API Reference

### PromptInput

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "ghost"` | `"default"` |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |
| `placeholder` | `string` | `"Ask anything…"` |
| `disabled` | `boolean` | `false` |
| `textareaProps` | `ComponentProps<typeof InputGroupTextarea>` | — |
| `className` | `string` | — |
